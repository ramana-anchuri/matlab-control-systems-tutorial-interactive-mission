# control-systems
This project is a collection of controller designs and control system experiments using MATLAB and Simulink.

Topics Including:

- Classic CPID ontroller
- LQR and LQG Controller
- Hybrid Controller
- State Space Models
- Model Uncertainty and its influence
- Control period and control performance
- System Identification

## Interactive Missions

The root [manifest.yaml](manifest.yaml) makes this checkout an Interactive
Missions marketplace with a draft **Cruise Control with LQR** starter mission.
It includes five guided tasks, hints, completion checks, and resume scripts.
See [Interactive Missions setup](INTERACTIVE_MISSIONS.md) for local catalog
preview, requirements, and publishing and launch instructions.
